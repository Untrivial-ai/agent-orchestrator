---
title: Runtime
description: Native terminal hosts, legacy tmux compatibility, and platform prerequisites.
---

AO selects a terminal runtime by platform. New macOS and Linux Terminal UI sessions use a native PTY host; existing sessions and startup fallback use tmux. Windows uses ConPTY.

| Platform | Runtime | Requirement |
| --- | --- | --- |
| macOS / Linux | Detached native PTY host for new sessions; [tmux](/plugins/runtimes/tmux) for legacy/fallback | Desktop bundles tmux; macOS preflight still requires it. |
| Windows | ConPTY | Built into supported Windows versions. |

Chat sessions use the provider's Chat interface instead of an agent terminal runtime. They can still open a separate shell in the session worktree from the desktop app.

Run `ao doctor` for runtime diagnostics. It still checks tmux on macOS/Linux; that check alone does not describe which host a new session uses.
