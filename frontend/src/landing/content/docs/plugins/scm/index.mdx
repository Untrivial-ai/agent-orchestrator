---
title: Source control and pull requests
description: GitHub and GitLab PR, CI, review, and mergeability support built into AO.
---

AO ships two SCM providers, GitHub and GitLab. Both observe the pull or merge requests associated with active sessions and feed concise facts into the lifecycle engine and desktop UI. They run side by side: each repository is routed by its remote, and a provider without usable credentials is skipped rather than disabling the other.

The provider tracks:

- pull request identity and state;
- check status and failing check names;
- mergeability and merge-conflict reasons;
- review decisions and unresolved human-review comment counts.

See [GitHub SCM](/docs/plugins/scm/github) and [GitLab SCM](/docs/plugins/scm/gitlab) for authentication and each provider's action surface. GitLab SCM also covers self-managed instances.
