---
title: Issue tracking
description: The current GitHub-only, opt-in issue intake capability.
---

AO currently ships one tracker adapter: [GitHub](/docs/plugins/trackers/github). GitLab and Linear are not supported by the Go rewrite.

Tracker intake is opt-in per project. It can discover matching GitHub issues and spawn workers, but v1 is read-only toward the tracker: AO does not comment on or transition issues as agent lifecycle changes.

<Callout type="warn">
	The tracker lane is still limited. Do not treat issue association as a complete two-way synchronization workflow.
</Callout>

Use the SCM capability for pull requests, CI, reviews, and mergeability; those facts are independent from tracker intake.
