---
title: Issue tracking
description: The current opt-in, read-only GitHub and GitLab issue intake capability.
---

AO ships two tracker adapters: [GitHub](/docs/plugins/trackers/github) and [GitLab](/docs/plugins/trackers/gitlab). Linear is not supported by the Go rewrite.

Tracker intake is opt-in per project. It can discover matching issues and spawn workers, but v1 is read-only toward the tracker: AO does not comment on or transition issues as agent lifecycle changes. Intake itself polls GitHub only today; the GitLab adapter backs `ao spawn --tracker-provider gitlab` issue hydration.

<Callout type="warn">
	The tracker lane is still limited. Do not treat issue association as a complete two-way synchronization workflow.
</Callout>

Use the SCM capability for pull requests, CI, reviews, and mergeability; those facts are independent from tracker intake.
