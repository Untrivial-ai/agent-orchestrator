## Native AO workflows on Windows <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/1025" />

Windows users can install and run the same AO dashboard, agents, and session workflows natively without WSL.

## Build and control staged agent pipelines <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/1645" />

The CLI can define, start, inspect, cancel, and resume staged agent pipelines, including parallel work and saved artifacts.

## Rename worker sessions from the sidebar <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/1748" />

Worker sessions can be renamed directly from the dashboard sidebar.
