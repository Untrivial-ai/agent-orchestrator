## The desktop app becomes the primary install path <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2201" />

The legacy ao start command now finds, downloads, and opens the desktop app instead of treating npm as the application channel.

## Stable and preview updates inside the desktop app <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2221" />

Desktop updates understand stable and preview channels and can install through the app's update runtime.

## Update controls and download progress in Settings <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2235" />

Global settings now expose migration and update-channel controls, with visible progress while the desktop app is downloaded.
