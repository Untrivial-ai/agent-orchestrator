## Push notifications when a session needs you <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2851" />

Paired iOS and Android devices can receive push notifications when a session needs attention, so work does not have to stay visible on the desktop.

## Standalone terminals for everyday shell work <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2861" /> <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3077" />

Open a shell without attaching it to an agent session, then keep its tabs scoped and named for the work at hand.

## Search and open links inside the embedded browser <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3085" />

The browser address bar now accepts searches as well as URLs, while links from the app can stay inside the embedded browser.

## Readable workspace diffs <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3013" />

The Changes view renders parsed diffs with clear gutters, hunk headers, additions, deletions, and a compact summary instead of raw diff text.

## Improvements

### Navigation

- **Search from the command palette and move between sessions with keyboard shortcuts.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3097" /> <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2954" />
- **Send a new task with Enter and insert a new line with Shift+Enter.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2955" />

### Notifications

- **Browse a paginated notification history from the redesigned notification center.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2922" />

### Desktop

- **The desktop shell now uses one framed layout across macOS, Windows, and Linux.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2937" />
- **Terminal tabs stay within the available width instead of overflowing.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3019" />

## Bug fixes

### Sessions

- **Failed scratch workspaces remain available for a retry.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3137" />
- **Sessions no longer remain stuck in an active state after the underlying run has stopped.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3117" />
- **Stopping one worker no longer leaks kill state into another worker.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3084" />
