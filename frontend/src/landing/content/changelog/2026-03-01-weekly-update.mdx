## Full managed-session support for Codex <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/154" />

Codex sessions gained the same managed lifecycle operations expected from other AO agents, including reliable launch and follow-up control.

## Live dashboard updates <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/249" />

Session state now reaches the dashboard as it changes, without waiting for a manual refresh.

## Large dashboards load in seconds, not minutes <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/244" />

Process information is shared across session checks, cutting a large-dashboard load from tens of seconds to a practical response time.
