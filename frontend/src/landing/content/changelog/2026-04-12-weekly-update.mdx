## Cursor joins the supported agent catalog <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/1076" />

Cursor joined the supported agent catalog with the same launch and session controls available to other agents.

## Start a session directly from a prompt <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/1069" />

A session can start directly from a prompt even when there is no tracker issue to attach.

## A ninety-percent smaller dashboard download <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/928" />

The dashboard's initial JavaScript payload was reduced by roughly ninety percent for a much faster first load.
