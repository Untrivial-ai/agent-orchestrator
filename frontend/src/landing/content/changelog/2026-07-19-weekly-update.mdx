## Start a new session without leaving the workspace <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2687" />

A keyboard shortcut or sidebar action can start a new agent session without leaving the current workspace.

## Drop files into terminals like a native app <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2644" />

Dropping a file into a terminal inserts its path the same way a native terminal does.

## Restart into ready updates from the sidebar <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2381" />

The sidebar now shows when an update is ready and lets you restart into it from the active channel.
