## One dashboard across every project <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/861" />

One dashboard now combines multiple registered projects while preserving each project's sessions and navigation.

## Run multiple orchestrators without worktree conflicts <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/870" />

Multiple orchestrators can run at the same time in isolated worktrees without colliding with each other.

## Live session state in browser tabs <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/848" />

Browser tabs and favicons update from live session state, making active work recognizable at a glance.
