## Switch Codex accounts without leaving AO <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4722" />

Codex accounts can be added and switched globally while sessions keep their account context.

## Persistent browser profiles and imports <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4135" />

In-app browser profiles can persist cookies and history, with an explicit import flow for an existing local profile.

## Project-level permission defaults <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4956" />

Each project can remember its permission defaults so repeated sessions start with the intended policy.
