## Use the desktop app in eight languages <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3465" /> <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3541" />

The desktop interface now supports Simplified Chinese, Japanese, Korean, Spanish, French, German, Brazilian Portuguese, and English.

## Pin sessions you return to <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3511" />

Important sessions can stay at the top of the sidebar instead of being displaced by newer work.

## Choose a reviewer for each session <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3477" />

Each session can use the reviewer agent that fits its work, with review passes collected in one place.

## Open settings without leaving the board <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3497" />

Settings now open as a modal over the current workspace, preserving context while configuration changes are made.
