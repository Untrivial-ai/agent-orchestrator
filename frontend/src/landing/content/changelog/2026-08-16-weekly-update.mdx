GitLab repositories and merge requests now work through the same project and review flows as other source-control providers.

## Faster, more polished mobile chat <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3843" />

Mobile chat gained a faster, more polished composer and better handling for long conversations.

## Automatic reviewer sessions for pull requests <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3338" />

Pull requests can start an interactive reviewer automatically, with policy controls for when that review should run.
