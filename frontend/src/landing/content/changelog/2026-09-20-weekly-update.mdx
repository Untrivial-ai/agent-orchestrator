## Standalone agent sessions <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4851" />

Start an agent for a quick task without first choosing or creating a repository. Standalone sessions keep lightweight work out of project history while preserving the same session controls.

## Browser tools when you need them <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5276" /> <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5396" />

Open a browser panel on demand instead of reserving screen space for it all the time. Expanded annotation tools make it easier to point an agent at the exact part of a page that needs attention.

## Safer session delete and restore <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5519" />

Delete sessions with one clear action and restore them without losing the terminal connection. Recovery also repairs workers that need to reconnect after a session returns.

## Project onboarding that explains itself <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5548" />

The project setup flow now guides you through repository access and GitHub authentication together, reducing the number of dead ends during first-time setup.

![The guided project onboarding flow](https://github.com/user-attachments/assets/53486628-c9a5-47f2-a869-b02b14637ee1)

## Improvements

### Performance

- **First-load download weight dropped from 2.8 MB to 0.96 MB.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5573" />
- **Projects with many sessions shut down concurrently, reducing wait time.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5187" />

### Agents

- **Worker and orchestrator defaults now follow how each role is actually used.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5347" />
- **Model pickers include search, making large provider catalogs easier to navigate.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5444" />
- **Active turns can be steered directly from `ao send`.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5389" />

### Updates

- **Update and restart keeps the app visibly active instead of making it appear closed.** <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5358" />
