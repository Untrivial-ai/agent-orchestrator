> Covers everything since **v0.10.0**. If you are on 0.10.3, you already have part of this.

v0.10.0 was the first release after a ground-up rewrite — Go daemon, tmux session layer, Electron shell. It worked, mostly. But a rewrite's first release is a promise, not a product.

0.11.0 replaces the fragile runtime foundation with a durable local daemon, then builds the desktop experience around clearer session, terminal, and pull-request workflows.

## Highlights

### Your phone is a real control surface

The mobile companion app went from a port to a shipping surface. Pair a phone to your daemon over LAN with a password via **Connect Mobile**, co-view terminals with pinch zoom and pan, and get **push notifications on iOS and Android** when a session needs you. Settings walks you through LAN or Tailscale pairing and links straight to the app. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2522" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2533" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2569" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2654" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2851" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2881" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2918" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2933" />)

Agents render Markdown and drive an embedded browser preview. Annotate directly inside it to point an agent at a specific UI element, and localhost links clicked in a terminal open there instead of bouncing you out of the app. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2455" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2548" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2610" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3085" />)

Every PR can now produce its own installable prerelease build, so testing an in-flight change means installing a real app rather than doing a checkout. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2459" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3039" />)

Projects can auto-start a worker session per assigned GitHub issue — polling, dedupe, pagination and per-project backoff — configured under **Tracker Intake** in project settings and the create-project flow. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2325" />)

## Reliability

This is where most of the cycle went.

**Sessions survive restarts.** Sessions now resume the agent's own native transcript rather than restarting cold, with a toast when AO has to fall back to replaying the saved prompt. Per-harness restore landed for OpenCode, Copilot, Agy, Kimi, Grok, Qwen, Goose and Vibe, backed by a test proving sessions survive daemon restart *and* upgrade. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2350" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2744" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2765" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2790" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2796" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2856" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2857" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2858" />)

**Model config actually reaches the agent.** The model you picked in settings was silently dropped for most agents. Closed across Codex, Cline, Goose, Auggie, Pi, Vibe, Autohand, Kimi, Kilocode, Qwen and Copilot, with Kiro now advertising its options at all. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2869" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2932" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2953" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2956" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2961" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2969" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2971" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2975" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2985" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2989" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2993" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3044" />)

## Under the hood

The agent adapter layer was consolidated, cutting ~3,100 lines of duplication into shared `agentbase` and `activitystate` packages. The release pipeline gained channel awareness, retried macOS sign/notary flakes, a guard on the `latest` desktop release, an advisory e2e gate against real installed builds before a stable cut, and a dispatchable unsigned build-artifacts workflow that emits the Linux `.deb`. On quality: a T0/P0 renderer smoke suite with `data-testid` instrumentation, a deterministic no-LLM fake harness for e2e, and TypeScript typechecking in frontend CI. Telemetry was capped in volume, switched to anonymous IDs, and no longer leaks raw CLI args into error events. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2266" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2415" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2489" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2683" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2692" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2696" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2697" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2829" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2864" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2978" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2986" />)

## Upgrading

GitHub Releases and Homebrew are the supported install paths; the npm package is frozen. Existing installs should update in place — the migration ordering fixes in this release specifically target the "it broke after updating" class of failure.
