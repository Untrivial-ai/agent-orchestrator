## Session names that reflect the task <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/1224" />

Session names now come from the task context, making parallel work easier to distinguish in lists and cards.

## Automatic cleanup after a pull request merges <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/1311" />

A session can terminate automatically after its pull request merges, keeping completed work out of the active queue.

## Resolve merge conflicts from the session card <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/1318" />

Pull-request cards now provide a direct conflict comparison and an easy way to copy the working branch.
