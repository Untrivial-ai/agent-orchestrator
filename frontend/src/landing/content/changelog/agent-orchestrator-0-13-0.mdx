> Covers everything since **v0.12.0**. The 0.12.1–0.12.12 patch releases carried most of the fixes but never got their own entries, so the whole cycle is folded into this one. If you are on 0.12.0, this is everything you skipped.

0.12.0 was polish on the foundation: languages, palette, pins, notifications. 0.13.0 is the cycle where the product grew new limbs. A cloud control plane now lives in the repo behind a flag. Chat stopped being a view and became a durable surface. The agent roster roughly doubled. And the two ugliest classes of failure left — a restart taking your in-flight turn with it, and a big diff freezing the inspector — both got structural fixes.

This release brings cloud orchestration into the main product, makes chat providers survive daemon restarts, broadens agent support, and improves real-time terminal behavior.

## Highlights

### AO Cloud is in the repo

The private control plane — a separate Go service with a 28-table PostgreSQL schema, WorkOS sign-in, GitHub App installations and webhooks, organization-scoped projects and sessions, durable message queues, event replay and cluster-safe SSE reconnects — now lives in this monorepo, wired to an authenticated Next.js Cloud UI through new `@aoagents/cloud-client` and `@aoagents/product-ui` packages and a public cloud contract. Desktop sign-in gained native WorkOS auth. Everything is flag-gated; nothing changes for local-only users yet. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4434" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3692" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4722" />)

### Chat is first-class, and it survives restarts

The composer was redesigned around resolved agent and model defaults, with a queued message dock that supports editing, cancel, drag-to-reorder and attachments that survive restarts. Queued turns can be promoted to steer the active turn. Claude Code conversations gained message editing, failed turns retry without retyping the prompt, and tool calls render as readable cards instead of raw dumps.

Under it all, Codex and the ACP chat providers are owned by authenticated detached hosts now: close the desktop app, restart the daemon, and the provider is re-adopted with its conversation snapshot, pending approvals and in-flight turn intact. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3657" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4649" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4684" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4715" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3838" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3858" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4256" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5027" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4529" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4766" />)

### Real-time terminal

The terminal is a duplex stream with predictive local echo now, backed by native PTY hosts on macOS and Linux, selectable Windows shells, line-boundary editing shortcuts on macOS, and tab cycling shortcuts. Output bursts are back-pressured instead of killing the WebSocket. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4763" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4768" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4473" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4727" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4517" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5199" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/3658" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4552" />)

## Reliability

The 409 fixes were mostly grind work, but a few groups deserve their name in lights.

**Queued messages became durable.** Edits persist with atomic delivery receipts, inline edits recover from durable branch receipts on reconnect, attachments survive editing and restarts, and a failed turn holds the queue instead of draining it into the same error. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5109" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5110" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5006" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5107" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5188" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5106" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5274" />)

**Terminals stop dying at the wrong moment.** Back-pressured PTY output, no more leaked shell renderer on window close, user shells preserved across relaunches, and focus restored after fullscreen and restart. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4552" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5150" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5040" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4988" />)

**Restore checks before it restores.** `--resume` verifies the persisted session before attaching, sessions can switch to terminal until they have real work, and OpenCode keeps its Plan Mode selection. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5214" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5053" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5015" />)

**Smaller fixes that mattered:** change log retention is bounded so the CDC table stops growing forever, nightly build stamps parse as UTC, percent-encoded ACP approval ids decode instead of failing, the resolve-comments route validates its PR number, and the board re-renders on change events instead of poll ticks. (<PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5103" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5115" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5193" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/5239" />, <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/4854" />)
