## Monitor and control sessions from your phone <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/266" />

The first phone app can monitor sessions, open details, send follow-ups, and handle attention while away from the desktop.

## Full lifecycle controls for OpenCode <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/315" />

OpenCode sessions became fully managed AO sessions that can be started, restored, messaged, and cleaned up consistently.

## Let a session claim its pull request <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/326" />

An agent session can claim a pull request so ownership and review state stay attached to the work.
