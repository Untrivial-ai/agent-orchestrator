## Safer agent selection and orchestrator switching <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2309" />

Project settings now show which agents are installed and authenticated, and changing the orchestrator avoids downtime if the replacement cannot start.

## Turn GitHub issues into trackable work <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2325" />

GitHub issues can enter AO as trackable work instead of being copied into a session by hand.

## Review status across every pull request in a session <PRBadge url="https://github.com/Untrivial-ai/agent-orchestrator/pull/2193" />

A session with several pull requests can show review state for all of them, not only the first one.
