## Short answer

Choose **Agent Orchestrator (AO)** when you want a free Apache-2.0 supervisor that tracks work from issue through PR, CI, and review across macOS, Windows, Linux, iOS, and Android. Choose **Superset** when you want a polished macOS agent workspace with remote hosts, scheduled automations, Linear/Slack, SOC 2 paperwork, and an MCP surface you can call from other tools.

Third-party pages that still describe AO as local-only with a deprecated CLI and no multi-device story are out of date. As of September 2026, AO ships a desktop app, a supported thin `ao` CLI against that desktop daemon, and iOS/Android companions over Connect Mobile. AO still has **no MCP server yet** (in progress)—do not treat that as shipped.

[Superset](https://docs.superset.sh/overview) is source-available under the Elastic License. [AO](https://orchestrator.inc/docs/) is Apache-2.0 and keeps the issue-to-merge loop as the product center.

## What AO uniquely has

- **Project orchestrator** that plans and delegates across workers, not only a per-workspace agent chat.
- **CI-failure and review-comment routing** back to the owning session after a PR is open.
- **Desktop + iOS + Android** against the same local daemon (Connect Mobile on a trusted home network).
- **Apache-2.0** on macOS, Windows, and Linux with about **25 harnesses**, GitHub and GitLab, and an **isolated browser per worker**.
- No seat pricing: free, BYO agent credentials.

## Where Superset is stronger

- **macOS workspace polish**: integrated editor, terminal, browser, and diffs in one surface.
- **Remote hosts, automations, Linear, and Slack** on paid tiers; AO has **no Linear yet** (in progress).
- **MCP server / CLI / SDK** so agents and scripts can drive Superset; AO's MCP server is in progress, not shipped.
- **SOC 2 Type II** and weekly changelog cadence that procurement teams often ask for.
- Team pricing and login-gated product packaging (Free / roughly $15–20 Pro / Enterprise).

## Frequently Asked Questions

### Is AO still “local-only” with no multi-device story?

No. The desktop app owns a loopback daemon on your machine, and Connect Mobile adds an opt-in LAN listener for the iOS and Android apps. That is not a hosted multi-user cloud; it is a real phone companion for the same projects and sessions.

### Is the AO CLI deprecated?

The legacy npm package `@aoagents/ao` is frozen at `0.10.0` and is no longer the recommended install path. The **desktop-bundled `ao` CLI** remains a supported thin client over the app-owned daemon for scripting and terminal workflows. Prefer [desktop download](https://orchestrator.inc/download/).

### Does AO expose MCP the way Superset does?

Not yet. AO does not ship an MCP server today; that work is in progress. Superset already documents MCP as part of its surface. Prefer Superset (or another MCP-first tool) if that integration is a hard requirement today.

### Are AO and Superset both “open source”?

AO is Apache-2.0. Superset is source-available under Elastic License 2.0, which is not an OSI open-source license. Both use your own coding-agent credentials rather than proxying model calls by default.
