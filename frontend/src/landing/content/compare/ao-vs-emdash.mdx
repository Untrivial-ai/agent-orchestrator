## Short answer

Choose **Agent Orchestrator (AO)** when you want a project orchestrator, automatic CI/review routing, and desktop-plus-mobile supervision under Apache-2.0. Choose **Emdash** when you want a YC-backed agentic development environment with broad issue-tracker coverage and first-class SSH remote projects—and you do not need an orchestrator agent or a phone app.

Both create isolated branches and worktrees per task. [Emdash](https://emdash.com/docs/tasks) is an ADE by design; [AO](https://orchestrator.inc/docs/) is an orchestration layer around the delivery loop.

## What AO uniquely has

- A **project orchestrator** that plans and delegates (Emdash is deliberately not an orchestrator product).
- **CI-failure and review-comment routing** to the owning worker after a PR opens.
- **iOS and Android** companions via Connect Mobile.
- The same Apache-2.0 license family, with a focus on durable session → PR → merge state across ~25 harnesses.

## Where Emdash is stronger

- **Issue-tracker breadth**: Linear, Jira, Asana, Monday, Trello, and more (nine-plus trackers). AO has GitHub and GitLab today; **Linear is in progress**, not shipped.
- **SSH remote projects** so the UI stays local while agents run on another machine.
- Auto-detection across **25+ agents** in a desktop ADE that also covers macOS, Windows, and Linux.
- A clear “no orchestrator by design” posture if you want humans (not a planner agent) to own task breakdown.

## Frequently Asked Questions

### Do AO and Emdash both support parallel worktrees?

Yes. Both isolate concurrent tasks with separate Git branches and worktrees by default.

### What is AO's main advantage over Emdash?

AO ships a project orchestrator and keeps CI/review feedback attached to the owning session, including on phones. Emdash is stronger when tracker coverage and SSH remotes matter more than an orchestrator agent.

### Does Emdash replace AO's mobile apps?

No. Emdash has no mobile companion. AO's iOS and Android apps talk to your desktop daemon over an opt-in LAN listener.
