# Changelog media assets

Place recorded GIFs, screenshots, and short videos for weekly entries here,
named to match each entry's `<MediaPlaceholder id="…" />` (or the final
`![…](/changelog/<slug>/<id>.ext)` path).

Example for the 2026-09-18 entry:

```text
public/changelog/2026-09-18-mobile-cloud-browser/mobile-revamp.gif
public/changelog/2026-09-18-mobile-cloud-browser/cloud-onboarding.gif
…
```

Until an asset exists, leave the `<MediaPlaceholder />` in the MDX so the
recording slot stays visible in preview.
